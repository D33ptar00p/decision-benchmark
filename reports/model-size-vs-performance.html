Does a bigger decision model help?

Model size against accuracy and speed, from the official JevBench harness (all 2,934 cases, 3 runs per model, AC power, local server). Latency is end to end: HTTP round trip plus the model. Only two sizes were benchmarked properly, so this shows what the data supports and nothing beyond it.

What the data says

  • Speed follows size. 4.8x more parameters (421M to ~2B) is 4.2x slower per case (27 to 113 ms). Both Laya checkpoints, which have the same size, run at the same speed.
  • Accuracy does not simply follow size. The larger model gains +3.3 points overall (63.3% to 66.7%), but unevenly: choice +18.4, yes/no -0.1, score -13.8 points. It is more accurate on only 9 of 22 datasets.
  • Training matters more than size here. At the same size (421M) the two Laya checkpoints differ by 17.5 points overall (45.8% against 63.3%), more than the 3.3-point gap that 4.8x more parameters buys.

Preliminary: four sizes on the same 40 cases

TEV1 0.8B and 4B were only checked on 40 cases (the first 10 of banking77, decision-bench, jevbench-noul and jevbench-score), so this section is a rough look, not a result. Intervals show how wide the uncertainty is. Nimble 9B was left out; a full 3-run test of the TEV models was started and stopped before it finished.
